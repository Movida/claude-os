# Contribuer

claude-os est un projet d'apprentissage personnel, écrit étape par étape avec Claude Code. Son historique est pensé pour se lire comme un cours : c'est pourquoi les pull requests ne sont pas fusionnées telles quelles.

Ce qui aide vraiment :

- **Une issue** pour un défaut, une explication fausse dans un commentaire, ou une meilleure façon de faire (avec une source : manuel Intel, code de Linux, wiki OSDev…).
- **Une question** sur un choix de conception : le pourquoi de chaque choix est censé être écrit dans le code, une question sans réponse est donc un défaut de documentation.

Le code et ses commentaires sont en français ; les issues sont bienvenues en français ou en anglais.
