# Les options IP d'un paquet reçu, et ce qu'en fait Linux 6.18 : vérifié sur
# l'hôte par linux/options-ip.c (sous sudo, make tests-hote-root), relu par le
# test de `compiler_options` (formats/tests/reseau.rs, cas_de_linux).
#
# Une ligne : le nom du cas, ses options (en hexadécimal, un multiple de 4
# octets), puis l'issue :
#   parametre N : un « problème de paramètre » qui désigne l'octet N de
#                 l'en-tête (les options commencent à 20) ;
#   livre HEX   : le paquet passe ; ses options sont alors HEX (Linux y a noté
#                 son adresse, 127.0.0.1, et l'heure : « .. », un octet qui
#                 change) ;
#   jete        : une route source, jetée sans rien dire ;
#   cipso N     : un « problème de paramètre » (octet N) pour une étiquette
#                 CIPSO, qui ne revient pas par lo : Linux y recopie les options
#                 du paquet fautif (`ip_options_echo`), et la recopie est jetée
#                 à son arrivée (linux/options-ip.c le voit à ses compteurs) ;
#   muet HEX    : le paquet passe (ses options sont alors HEX), mais Linux ne
#                 répond pas au port fermé : il ne saurait pas renvoyer ces
#                 options (`ip_options_echo`), et se tait.
#
